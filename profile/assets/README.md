# Re:CODESYS brand assets

All SVGs have text converted to outlines; they render the same everywhere without web fonts.
Colours: red `#CC2211`, greys `#CFCFD1 / #A7A7A9 / #8B8B8D`, wordmark grey `#5A5A59`, dark tile `#1F2225`, light tile `#F7F7F8`.
Wordmark typeface: Source Sans 3 Black (open licence). "Re:" on the block: Space Grotesk Bold.

| File | Use |
|---|---|
| `symbol.svg`, `symbol-dark.svg`, `symbol-transparent.svg` | The mark alone. `avatar-*.png` are rendered from these — use `avatar-light-1024.png` as the organisation avatar. |
| `lockup-horizontal-*.svg` | Mark + CODESYS side by side. For headers, docs, slides. |
| `lockup-square-*.svg` | Mark above CODESYS. For app icons, social profiles, print. |
| `banner-*.svg` | 1280×400 hero for the organisation README (`<picture>` switches light/dark). |
| `alternatives/` | The same lockups in the other three candidate typefaces (Fira Sans, Montserrat, Nunito Sans). Not in use. |
| `archive/` | Earlier explorations (v1 reply-arrow mark, v2 blocks with a "Re:CODESYS" wordmark). Not in use. |

Rules of thumb

- The "Re:" appears once. Lockups carry it on the block, so the text next to it is `CODESYS`, never `Re:CODESYS`.
- The banner and the square lockup are redundant: never place both on the same page.
- Don't recolour, skew, add effects or redraw the blocks. Don't set "CODESYS" in another typeface next to the mark.
- This mark is ours. It is not the CODESYS logo and must not be presented as one; see [LEGAL.md](../../LEGAL.md).
